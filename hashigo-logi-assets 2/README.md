## 制作への引き継ぎ
背景は約1672×941px（高速道路のみ1672×940px）。FVではCSSのobject-fit: cover等で表示枠に合わせてください。
ロゴは画像生成によるPNGで、Bookman Old Styleの実フォントを使った組版・ベクターデータではありません。透過ロゴの生成は輪郭品質が安定しなかったため、品質不良の透過版は同梱していません。背景付き版はそのままスライド等へ配置できます。写真に重ねる透過版やSVGが必要な場合は、採用形状のトレースと正式フォントでの組版が必要です。
FVは構成確認用の画像です。実装時は背景画像、ロゴ、ナビゲーション、中央コピーを別要素として配置してください。
画像の生成・編集は内蔵image_genを使用しました。
