3PL（物流代行）の見積もりを複数社から取ると、料金の項目名も単位もばらばらで、どこが安いのか分からなくなりがちです。結論として、比べるときは**同じ条件（同じ物量・同じ作業範囲）で月額の総額を出し直す**ことが必要です。

この記事では、3PLの見積もりに出てくる主な料金項目と、比較する前に確認しておきたいチェックリストをまとめます。

## 3PLの料金は、大きく4つに分かれる

会社によって呼び方は違いますが、3PLの料金はおおむね次の4つに分けられます。

| 区分 | 主な項目 | 単位の例 |
|---|---|---|
| 入荷にかかる費用 | 入荷料、検品料、棚入れ料 | 1個・1ケース・1パレットあたり |
| 保管にかかる費用 | 保管料 | 1坪・1パレット・1棚・1個あたり（月額） |
| 出荷にかかる費用 | ピッキング料、梱包料、出荷作業料、資材費、配送料 | 1件・1個あたり |
| その他 | システム利用料、流通加工費、返品処理料、最低保証料、初期費用 | 月額・1件・1時間あたり |

見積もりを比べにくくしている原因は、**どこまでが1つの料金に含まれているか**が会社ごとに違うことです。たとえば「出荷作業料」に配送料まで含む会社もあれば、ピッキング・梱包・資材・配送をすべて別にしている会社もあります。

ハシゴロジの3PLでは、出荷作業料（1個550円〜・60サイズの目安・税抜）に入荷・ピッキング・検品・梱包・配送までを含め、保管料と流通加工費を別にしています。

## 比べる前に確認したいチェックリスト

見積もりを受け取ったら、次の項目を確認してください。抜けている項目は、問い合わせて明らかにしておくと、契約後の「想定外の請求」を防げます。

### 料金の範囲

- 出荷作業料に、資材費（段ボール・緩衝材）は含まれているか
- 出荷作業料に、配送料は含まれているか。含まれる場合、どのサイズ・地域までか
- 1件に複数の商品が入るとき、2個目以降の料金はいくらか
- 納品書やチラシの同梱は、追加料金がかかるか

### 保管料の数え方

- 保管料は坪・パレット・棚・個数のどれで計算するか
- 月の途中で入荷・出荷した在庫は、どう数えるか（月末在庫か、平均か）
- 在庫が少ない月でも、最低限かかる保管料はあるか

### 固定でかかる費用

- 最低保証料（物量が少なくても払う月額）はあるか
- システム利用料は月額いくらか
- 初期費用や、他社倉庫からの移管にかかる費用はあるか

### 物量が変わったとき

- 物量が増えたとき、単価は下がるか。その条件は契約前に決まっているか
- 繁忙期だけ物量が増える場合、追加料金はかかるか

### 作業とミスの扱い

- 誤出荷が起きたとき、再送の送料はどちらが負担するか
- 返品が戻ってきたときの検品・再入庫の料金はいくらか
- 流通加工（ラベル貼り・セット組みなど）は、どう見積もるか

## 同じ条件で総額を出し直す

チェックリストで確認した内容をもとに、各社の見積もりを**自社の実際の物量**に当てはめて、月額の総額を出し直します。

**比較表の例**（条件をそろえるための表です。数字は自社の見積もりを入れてください）

| 前提：月400件・平均1.2個/件・保管3パレット | A社 | B社 | C社 |
|---|---|---|---|
| 入荷にかかる費用 | | | |
| 保管料 | | | |
| 出荷作業料（ピッキング・梱包・資材） | | | |
| 配送料 | | | |
| システム利用料 | | | |
| 最低保証料との差額 | | | |
| **月額の総額** | | | |
| **1件あたり** | | | |

ポイントは、**単価ではなく1件あたりの総額で比べる**ことです。単価の安さを強調した見積もりでも、資材費や配送料、システム利用料を足すと逆転することがよくあります。

## 見積もりで差がつきやすい5つのポイント

チェックリストの中でも、特に会社ごとの差が大きく、総額を左右しやすいのが次の5つです。

### 1. 保管料の単位と数え方

保管料は、坪・パレット・棚・個数など、会社によって単位が違います。同じ在庫量でも、坪単位では広めに見積もられ、個数単位では少量の在庫が割安になる、といった違いが出ます。さらに、月末時点の在庫で数えるのか、月の中で最も多かった日の在庫で数えるのかでも金額が変わります。立ち上げ期で在庫が少ない場合は、少量でも割高にならない単位かを確認してください。

### 2. 1件に複数の商品が入るときの料金

EC物流では、1件の注文に複数の商品が入ることがよくあります。1件あたりの料金なのか、1個あたりの料金なのかによって、まとめ買いの多いショップでは総額が大きく変わります。自社の注文の「1件あたりの平均個数」を出しておくと、見積もりを正しく比べられます。

### 3. 資材費の扱い

段ボールや緩衝材の費用が、出荷作業料に含まれているか、別に請求されるかを確認します。別請求の場合、サイズごとの単価と、自社で指定した資材（ロゴ入りの箱など）を使う場合の扱いも聞いておきましょう。

### 4. 配送料の条件

配送料が出荷作業料に含まれる場合は、どのサイズまで、どの地域までが対象かを確認します。含まれない場合は、運送会社ごとのサイズ別・地域別の運賃表をもらい、自社の出荷先の分布に当てはめて計算します。沖縄県や離島は、別料金になることが多い点にも注意してください。

### 5. 固定費（最低保証料・システム利用料）

物量が少ない時期は、単価よりも固定費の影響が大きくなります。月額の最低保証料やシステム利用料があると、出荷件数が少ない月の1件あたりの総額が跳ね上がります。立ち上げ期は、固定費の有無と金額を最優先で確認してください。

## 見積もりを依頼するときに準備するもの

見積もりの精度は、渡す情報の量で決まります。次の情報をそろえて依頼すると、あとから金額が変わる心配が少なくなります。

| 準備するもの | 内容の例 | なぜ必要か |
|---|---|---|
| 商材の情報 | 種類、サイズ、重さ、壊れやすさ | 保管方法と梱包資材が決まる |
| 出荷の実績 | 月間出荷件数、1件あたりの平均個数、繁忙期の物量 | 作業量と人員の見積もりに使う |
| SKUの数 | 商品の種類の数（色・サイズ違いを含む） | 保管の棚数とピッキングの手間に影響する |
| 保管量 | 常に置いておきたい在庫の量 | 保管料の算出に使う |
| 必要な作業 | ラベル貼り、ギフト包装、同梱物、セット組み | 流通加工費の見積もりに使う |
| 使っているシステム | カート、受注管理システムの名前 | 連携の方法と費用が決まる |
| 出荷先の分布 | 地域ごとの出荷の割合 | 配送料の試算に使う |

過去数か月分の出荷データ（注文ごとの商品と配送先）を渡せると、より実態に近い見積もりになります。

## 料金以外に比べておきたいこと

総額が近い場合は、次の点で選ぶと失敗しにくくなります。

- **連携できるシステム**：いま使っているカートや受注管理システムと、そのままつながるか
- **流通加工の柔軟さ**：ラベル貼りやギフト包装など、自社のやり方に合わせてもらえるか
- **在庫と出荷の見え方**：在庫数や出荷状況を、いつでも確認できるか
- **小ロットへの姿勢**：立ち上げ期の少ない物量でも、きちんと対応してもらえるか

## よくある質問

### 3PLの見積もりには、どんな情報を渡せばよいですか。

商材の種類とサイズ、月間の出荷件数、1件あたりの平均個数、SKU（商品の種類）の数、保管したい量、必要な流通加工を伝えると、精度の高い見積もりが出ます。過去の出荷データがあれば、それを渡すのが一番確実です。

### 見積もりが「一式」になっている場合はどうすればよいですか。

一式の見積もりは、物量が変わったときにいくらになるかが分かりません。この記事のチェックリストを使って、項目ごとの単価と、どこまでが含まれているかを確認してください。

### 最低保証料とは何ですか。

物量が少ない月でも、最低限支払う月額のことです。立ち上げ期で物量が読めない場合は、最低保証料の有無と金額を必ず確認してください。

### 契約したあとに料金が変わることはありますか。

物量や作業の内容が見積もりの前提から大きく変わった場合は、料金が見直されることがあります。物量が増えたときに単価がどう変わるか、作業が増えたときにどう見積もり直すかを、契約前に決めておくと安心です。

### 見積もりは何社くらいから取ればよいですか。

2〜3社から取ると、相場感をつかみやすくなります。ただし、数を増やすより、同じ条件で比べることのほうが大切です。この記事の比較表を使って、条件をそろえてから比べてください。
