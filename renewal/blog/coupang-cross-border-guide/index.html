日本からCoupang（クーパン）で売るには？韓国越境ECの始め方と、物流・関税で失敗しないポイント

韓国のEC市場に日本の商品を売るなら、Coupang（クーパン）は最初に検討したいモールです。日本企業は、韓国に法人をつくらなくても越境で出店できます。

ただし、売れるかどうかを決めるのは出品より物流と関税の設計です。この記事では、Coupangで売り始めるまでの流れと、日本からの配送方法の選び方、関税で失敗しないためのポイントを、越境ECの物流を管理してきた立場から整理します。

Coupangの売り方は大きく2つ

日本企業がCoupangで商品を売る方法は、大きく2つあります。

売り方仕組み向いている会社
マーケットプレイス出店自社が出品者になり、価格や在庫を自分で管理して販売するまず小さく試したい、価格を自社で決めたい
卸取引（Coupangが仕入れて販売）Coupangが商品を仕入れ、自社の物流網で販売・配送するすでに韓国で一定の需要があり、量を売りたい

最初はマーケットプレイスで出店し、売れ行きを見てから物流や取引の形を変えていくのが現実的です。出店の条件や手数料はカテゴリや時期によって変わるので、出店前にCoupangの出店窓口で最新の条件を確認してください。

出店から販売開始までの流れ

  1. 販売する商品を決める：韓国で売れる見込みと、規制上の扱い（後述）を確認する
  2. 出店アカウントを開設する：会社情報、銀行口座、本人確認書類などを登録する
  3. 商品ページを韓国語でつくる：翻訳ではなく、韓国の検索語やレビューで使われる言葉に合わせる
  4. 配送方法を決める：日本からの小口配送か、韓国内の倉庫を使うか（次の章）
  5. 価格を決める：送料・関税・手数料を引いても利益が残るかを確認する
  6. 販売開始と広告：最初はレビューが集まるまで、広告と販促で露出をつくる

つまずきやすいのは3と5です。日本語の商品説明を機械的に訳しただけのページは、韓国の消費者が検索する言葉と合わず、見つけてもらえません。

日本からの配送と、韓国内の倉庫の使い分け

配送方法は、販売の段階に合わせて切り替えるのが基本です。

段階配送方法メリット注意点
立ち上げ期注文ごとに日本から小口で発送在庫を韓国に置かなくてよい、少量から試せる届くまでに日数がかかる、1件あたりの送料が高い
販売が伸びてきたら韓国内の倉庫（Coupangの物流サービスなど）にまとめて納品配送が速くなり、購入率が上がりやすい在庫を先に送るので、売れ残りのリスクがある

韓国の消費者は配送の速さに慣れています。立ち上げ期は日本からの小口発送で売れ行きを確かめ、売れる商品が見えてから韓国内の倉庫にまとめて送ると、在庫リスクを抑えながら配送を速くできます。

関税と通関で失敗しないポイント

150ドルの免税基準を意識して価格と同梱を決める

韓国では、個人が使う目的の小口の輸入品は、商品価格が150米ドル以下（米国からの輸入は200米ドル以下）であれば、関税と付加価値税が免除されます。150ドルを超えると、超えた分だけではなく全額が課税対象になる点に注意が必要です（出典：ジェトロ「小口貨物の通関制度：韓国」）。

まとめ買いで150ドルを超えると、購入者に想定外の税金がかかり、受け取り拒否やクレームにつながります。セット商品の価格設定や、1回の注文で送る量は、この基準を踏まえて決めてください。

個人通関固有符号の入力を案内する

韓国の個人が海外から商品を受け取るには、個人通関固有符号（個人ごとの通関用の番号）の提出が必要です。注文時に正しく入力してもらえないと、通関で止まってしまいます。

規制のある商材は、出品前に確認する

化粧品、食品、電気製品、子ども用品などは、韓国の規制や安全認証（KC認証など）の確認が必要になる場合があります。販売形態（個人宛ての越境配送か、韓国内の在庫からの販売か）によっても扱いが変わるため、出品前に確認してください。最新の制度はジェトロの「小口貨物の通関・関税制度（韓国）」が参考になります。

韓国で売れる商品ページのつくり方

商品ページは、韓国の消費者が「検索で見つけ、比べて、安心して買える」ことを基準につくります。日本のページをそのまま訳すと、次の点で弱くなりがちです。

検索される言葉で商品名をつける

韓国の消費者が検索窓に入れる言葉は、日本語を直訳した言葉と一致しないことがあります。商品名には、商品の種類、ブランド名、容量やサイズ、使う場面など、実際に検索される言葉を入れます。競合の商品名や、レビューでよく使われている言葉を参考にすると見つけやすくなります。

画像で伝える情報を増やす

韓国のECでは、縦に長い詳細画像で商品の特徴や使い方を説明するページがよく見られます。サイズ感、使用前後の比較、成分や素材、日本製であることの説明などを、文字だけでなく画像で伝えると、購入の判断材料が増えます。

不安を先回りして解消する

越境で買う購入者は、「いつ届くか」「関税はかかるか」「本物か」を気にします。届くまでの目安日数、150ドルの免税基準、正規品であることを、商品ページや注意事項にはっきり書いておくと、問い合わせと受け取り拒否を減らせます。

立ち上げから3か月のロードマップ

Coupangでの立ち上げは、次のような流れで進めると、手応えを確かめながら投資を広げられます。

時期やること確認すること
1か月目出店手続き、商品を数点に絞って出品、韓国語の商品ページ作成商品ページが検索で表示されるか、規制上の問題がないか
2か月目広告とクーポンで露出をつくり、最初のレビューを集める閲覧数に対する購入率、レビューの内容、問い合わせの傾向
3か月目売れ行きのよい商品に絞り込み、価格や画像を改善する1個あたりの利益、配送日数への不満の有無、韓国内倉庫に移すべきか

最初から多くの商品を出すより、売れそうな数点に絞って改善を重ねるほうが、レビューが集まりやすく、検索でも上位に表示されやすくなります。

利益が残るかを、出品前に計算する

越境ECで多い失敗は、売れたのに利益が残らないことです。価格を決める前に、1個あたりで次を計算してください。

利益 ＝ 販売価格 －（商品原価 ＋ モールの手数料 ＋ 国内の梱包・出荷費 ＋ 国際送料 ＋ 関税・税金 ＋ 広告費）

特に国際送料は、商品のサイズと重さで大きく変わります。梱包を少し小さくするだけで送料の区分が変わることもあるので、出品前に実物で梱包サイズを確かめておくと安心です。

また、韓国のモールでは割引クーポンやセールへの参加が売れ行きを大きく左右します。セール時の割引率を差し引いても利益が残るか、通常価格だけでなくセール価格でも計算しておくことが大切です。

韓国越境ECでよくある失敗

最後に、韓国向けの越境ECで起きやすい失敗をまとめます。

  1. 日本での人気をそのまま当てにする：日本で売れている商品でも、韓国では競合が多かったり、使い方の習慣が違ったりします。小さく試して反応を見ることが大切です。
  2. 商品ページを翻訳だけで済ませる：検索される言葉と合わず、見つけてもらえません。現地の言葉でつくり直す必要があります。
  3. 関税の基準を考えずにセット商品をつくる：150ドルを超えると購入者に税金がかかり、受け取り拒否につながります。
  4. 問い合わせへの返信が遅れる：韓国語の問い合わせに数日返信できないと、評価が下がります。返信の体制を最初に決めておきます。
  5. 在庫を一気に韓国へ送る：売れ行きが見えないうちに大量の在庫を送ると、売れ残りのリスクを抱えます。

よくある質問

韓国に法人がなくてもCoupangに出店できますか。

できます。日本の法人のまま、越境で出店できます。出店に必要な書類や条件は時期によって変わるため、Coupangの出店窓口で最新の情報を確認してください。

日本から発送すると、韓国の購入者に届くまで何日かかりますか。

配送方法によって変わりますが、日本からの小口発送では、韓国内の倉庫から発送する場合より日数がかかります。販売が伸びてきたら、韓国内の倉庫に在庫を置くことを検討してください。

150ドルを超える注文はどうなりますか。

韓国の小口輸入の免税基準（150米ドル以下）を超えると、全額が関税と付加価値税の対象になり、購入者に税金がかかります。高額な商品やまとめ買いの多い商品は、価格設定と案内を工夫する必要があります。

韓国語ができる社員がいなくても運用できますか。

できます。商品ページの作成、問い合わせ対応、広告の運用を、韓国語のできる運用代行会社に任せる方法があります。社内では、商品の情報提供と在庫の管理、売上の確認に集中できます。

どんな商品が韓国で売れやすいですか。

化粧品、生活雑貨、食品、ホビー用品など、日本製であることが品質の安心につながる商品は関心を集めやすい傾向があります。ただし、カテゴリごとに競合の状況や規制が違うため、出品前に競合の商品と価格帯、規制上の扱いを確認することが大切です。

まとめ

  • Coupangには、日本企業が韓国法人なしで越境出店できる
  • 立ち上げ期は日本からの小口発送で試し、売れる商品が見えたら韓国内の倉庫に送る
  • 150ドルの免税基準と個人通関固有符号、規制のある商材の確認が、物流と関税で失敗しないポイント
